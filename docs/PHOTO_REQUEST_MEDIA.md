# Private photo-request replies and public additions

Seller photo replies use a separate private storage path from public listing media. The server validates JPEG, PNG, or WebP uploads (up to 10 MiB), converts them to WebP, and attaches at most ten photos to one private reply. Participants may fetch attached photos with bearer authentication; each GET checks authorization and sends `private, no-store` headers. Administrator access is audited. Attached private photos do not expire automatically when the listing is Sold or the photo request closes. Unattached upload leases are removed after 24 hours. A bounded storage sweep also removes private tagged blobs older than 24 hours that have no photo row reference, including bytes left by interrupted uploads or processing.

The seller may select an individual reply photo and caption for public addition. This creates a pending moderation record; the live listing and its existing photos stay unchanged. An independent administrator may reject it or approve it. Approval copies processed private image bytes into a separate public media record, then atomically checks the selection revision, listing revision, owner and active account, public status, moderation state, and 30-photo limit before appending the public copy. If the check fails, the copied storage files are discarded. The private original stays with the conversation, and unselected photos never enter a public projection.

Set `ADMIN_PORTAL_URL` in the Convex deployment to the exact admin portal origin for private admin previews, alongside the existing `APP_URL` for marketplace access. Set `NEXT_PUBLIC_CONVEX_SITE_URL` in the admin portal to the matching Convex site URL. The private download endpoint accepts only those configured origins and still requires a participant or administrator bearer token; administrator reads are audited.

GBXMRKT-46 account deletion must preserve participant-only read access to private replies while disabling new messaging and removing the deleted seller's public listing and share surfaces. Closed structured-offer history has a separate six-calendar-month cleanup rule.
